# Web Research

You are performing web research.

## When to use

Use this skill when the user asks for:

- Current or recent information
- News
- Product research
- Comparisons that depend on current information
- Information about current software/library versions
- Information that you are not confident about
- Research requiring citations
- Finding official documentation or sources

## Research workflow

1. Identify the exact question.
2. Break complex questions into searchable subquestions.
3. Search using Brave Search.
4. Prefer primary sources:
   - Official documentation
   - Official company websites
   - Government sources
   - Academic papers
   - Original announcements
5. Open and inspect relevant results rather than relying only on search snippets.
6. Cross-check important claims using multiple independent sources.
7. Prefer recent sources when freshness matters.
8. Distinguish facts from inference.
9. Do not invent information when sources are unavailable.

## Search strategy

Start with a focused search.

If the results are insufficient:

- Try alternative wording.
- Search for the official source.
- Search for the specific product/version/date.
- Search multiple independent sources.

Avoid performing many redundant searches.

## Source quality

Prioritize:

1. Primary sources
2. Official documentation
3. Government/academic sources
4. Reputable technical publications
5. Community discussions

Treat forums, Reddit, blogs, and social media as secondary sources unless the user specifically wants community opinion.

## Answering

When research is complete:

- Give the answer first.
- Explain the important evidence.
- Mention uncertainty when appropriate.
- Include useful source references.
- Do not claim to have verified something you did not verify.

For software questions, prefer current official documentation over model memory.
